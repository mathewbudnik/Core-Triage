## What this project is
CoreTriage is an **all-in-one climbing progression app**: it reads what kind of climber you are (a 5-axis "Pentagon" skill radar) and gives a fun, gamified path to improve, with **injury triage/rehab, AI + 1:1 coaching, and movement analysis as supplements**. Climbing-injury triage is the brand origin; progression is the spine. Python/FastAPI backend (`main.py` ~80KB, `database.py` ~96KB, `src/`), React + Vite frontend (`frontend/`), Postgres.

## The job we're doing
A full **UI redesign + modernization**, done in phases. The owner was unhappy with a cluttered, "stacked", half-migrated UI. We locked one design language and are migrating the whole app to it, then deepening the product. The owner wants a **modern, high-end, clean, "snappy"** feel. He reviews via the running app + browser mockups, and gives fast directional feedback.

## Design system — "Almanac" (LOCKED, do not relitigate)
Parchment editorial / field-guide aesthetic. **Single source of truth: Tailwind `ct-*` tokens (`frontend/tailwind.config.js`) + CSS vars (`frontend/src/styles/brand-tokens.css`) + `.ct-*` utility classes (`frontend/src/index.css`).**
- **Surfaces:** paper `#e7ddc6` (app bg), side `#e0d4b6` (sidebar), card `#f4ecdb` (field-cards), edge/ct-rim `#bcae8a`, hairline `rgba(42,39,34,0.13)`.
- **Ink (text):** ink `#2a2722`, ink-soft `#5f594c`, ink-muted `#8d8472`. `cream #fdf6ea` = text ON colored fills only.
- **Accents:** clay `#c58a77` (primary action / active nav), clay-deep `#b06a4f`, ochre `#d7ac5b`, sage `#97a886`, sage-deep `#5f7a4e`. Foil gradient for rare prestige.
- **5 semantic skill colors (same color everywhere a skill appears):** Power `#b85c44`, Crimp `#c79a3c`, Dynamic `#5f87a0`, Technique `#7f9466`, Mobility `#a06f8a`. Source: `frontend/src/lib/skills.js` (`skillColor`, `SKILL_KEYS`).
- **Type:** Fraunces (display/serif), Inter (body), JetBrains Mono (labels/data/eyebrows), Caveat (hand annotations).
- **Texture:** newspaper grain overlay on `#root::after` (multiply, on top). Print marks, hairlines, box-score stat rows.
- **Tiers:** `lib/tier.js` `TIER_TOKENS` re-paletted to MUTED stones (no neon).

### Hard conventions / constraints
- **No old-palette hex anywhere.** Grep gate must be 0: `217,119,87 #d97757 #f0a875 #1c2520 #243530 #1f2924 #f0f5ed #c8d3c4 #14b8a6 #fb7185 #fbbf24 #95a698 #7dd3c0 #a78bfa text-white rgba(255,255,255` (excluding tests). `text-ct-cream` resolves to ink — never use it on a parchment fill; use `text-ink`, and `text-cream` only on a colored fill.
- **No emojis in UI** — use lucide-react icons.
- **Identity is plain language, NEVER coined archetype names** ("Slabber"/"Crimper" are banned). Use `frontend/src/lib/identity.js` `identityPhrase(axes)` → `{title, gap}` (e.g. "Powerful & crimp-strong." / "Technique is your gap.").
- **Modern patterns:** floating **frosted** (translucent + backdrop-blur) nav; **field-cards** (`.ct-surface`); responsive (mobile compact/segmented, desktop 2-col grid `max-w-4xl`); snappy motion ~0.14–0.16s, spring (stiffness 420 / damping 34).
- When polishing: **visual only — do NOT change data/logic/state/endpoints/props/routing, paywall gates, or safety/medical content** (triage red-flag referral CTAs + "educational, not a diagnosis" disclaimers, and the **Movement Analyzer paid gate**).

## The Pentagon (the product centerpiece) — DONE
- **Scoring (grade-anchored, absolute):** `main.py _compute_current_pentagon`. Each axis = hardest grade SENT in that style → value `≈ min(10, 2 + 0.7·V)` (V0≈2, V4≈4.8, V7≈6.9, V10≈9, V11+≈9.7). Unlogged styles sit at a floor of 30% of apex, so the shape is small for beginners and **grows with grade** (never pre-filled). Empty = no sends → `None` (renders grid only). Helpers `_grade_to_vnum`, `_vnum_to_value` nearby.
- **Visual (FIFA stat-card):** `frontend/src/components/identity/Pentagon.jsx`. Filled radar, **skill-tinted fill leaning to the strongest skill**, ink outline, skill-colored vertex dots, the stat value on each axis. `mini` variant for the sidebar emblem; empty = grid only.
- Known gap: `frontend/src/lib/stats.js deriveStatShape` (used by `HubStyleStrip`) still uses the OLD *relative* model — not yet aligned to the grade-anchored backend. Minor inconsistency to fix later.

## Working notes / gotchas
- Big parallel workflows (4+ heavy agents) can hit the **session token limit** — do tab-scale polish in **2-tab batches**. The pool is shared across main loop + workflows.
- Interrupted workflows leave **partial uncommitted edits on disk** — re-audit `git status` before committing/redoing.
- Commit only Co-Authored-By-free messages (project policy). Commit/push to main only when the owner asks; we've been committing to the feature branch as we go.
- `git -C <root>` for git ops (the Bash cwd sometimes persists into `frontend/`).
